# Harbor 1.3.1

## Fixes

- Open images inside Harbor instead of launching the system image viewer.
  Zoom in, scroll, or choose Fit; Close and Escape return to the composer.
  Missing images show an error without losing an unsent draft.
- Keep nickname drafts when the helper is unavailable and show readable
  feedback instead of silently clearing the input.
- Dismiss an image preview when its conversation or contact binding changes.

This is a UI update. The protocol-17 helper, identity, history and file-transfer
formats are unchanged. It does not add automatic migration from a running
OmaQ helper; follow the existing installation/recovery guidance for that case.

## Verification

Native Omarchy interaction checks on Dell Optiplex and BMAX B4 Plus verified
the image fix against machines that reproduced the external viewer crash.
Further checks covered zoom/scroll/Fit, missing images, draft preservation,
compact layout and demo send/reply. The nickname fixture covered unavailable
helper feedback and a correlated successful save.

All ten real TCP-relay checks passed with the unchanged helper: large encrypted
direct/group messages, history, editing, search, rejection of oversized text,
pending-send shutdown protection, a 12 MiB file and a 4K image. See the
[image verification](../stages/image-preview.md) and
[nickname verification](../stages/nickname-draft.md) for scope and artifacts.

Supported/tested target: x86_64 Omarchy with Quickshell 0.3.1 and Hyprland
0.56.2. This does not establish support for other CPU architectures.
